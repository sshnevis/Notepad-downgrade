# Notepad windows 11 trick for downgrade

If you are also a programmer or have recently migrated to Windows 11 and were surprised by the new Notepad, read this article.

Although Windows 11 has many good things. But the convenience that simple Notepad had in previous Windows like Windows 7 or 10, is never felt in new notepad of Windows 11.
Sometimes it is even annoying to close and save.

## Solution:
 1. Open Notepad
 2. Click on Setting icon
 3. Set these settings
- [ ] WordWrap = OFF
- [ ] Formatting = OFF
- [x] Opening files = Open in new window
- [x] When Notepad start = Start new session and discard unsaved changes
- [x] Recent Files = ON
- [ ] Spell Check = OFF
- [ ] Autocorrect = OFF
- [ ] Copilot = OFF
